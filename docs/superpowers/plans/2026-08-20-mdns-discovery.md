# mDNS Device Discovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the Capacitor app scan for rtl433 receivers on the LAN via mDNS and add one to the Sources tab with a tap, after bumping Capacitor 7 → 8 (a prerequisite the mDNS plugin requires).

**Architecture:** `app/` (the Capacitor shell) gains `@devioarts/capacitor-mdns` as a native plugin dependency. `dashboard/` (the shared web UI, loaded by both the plain browser and the app's WebView) gains the same package plus `@capacitor/core` as *its own* dependencies too — `dashboard/src/sources.jsx` imports both directly and esbuild bundles them into `dist/index.html`, so they must resolve from `dashboard/node_modules`, not just `app/node_modules`. A `<ScanButton>` renders only under `Capacitor.isNativePlatform()`, calls `mDNS.discover()`, and filters results by service-name prefix.

**Tech Stack:** Capacitor 8, `@devioarts/capacitor-mdns` 0.1.0, Preact, esbuild, Playwright, node:test.

## Global Constraints

- Capacitor packages (`@capacitor/core`, `@capacitor/android`, `@capacitor/ios`, `@capacitor/cli` in `app/`; `@capacitor/core` in `dashboard/`) go to `^8.0.0` — the mDNS plugin's peer dependency floor.
- `@devioarts/capacitor-mdns` pins `^0.1.0` in **both** `app/package.json` and `dashboard/package.json` (see Architecture above for why both).
- The plugin's exported symbol is `mDNS` (capital DNS, not `Mdns` — verified against the published package's `dist/esm/index.js`).
- **Design deviation from the spec file** (`docs/superpowers/specs/2026-08-20-mdns-discovery-design.md`), decided in this planning session:
  - Android's NSD API exposes no TXT records (confirmed in the plugin's own Kotlin source: `"Android NSD has no public API for TXT records"`), so the spec's `s.txt?.rtl433 === '1'` filter never matches on Android. Filtering is **service-name-prefix based on both platforms** instead: a receiver's mDNS instance name is always `rtl433-<macsuffix>` (from `mdnsHostname()` in `WebReceiver.ino`, using the existing `MDNS_PREFIX` default), so no receiver firmware change is needed. **The spec's Phase B (receiver TXT record) is dropped entirely** — nothing consumes it.
  - **iOS discovery is in scope** (the spec marked it out of scope). The plugin's `discover()` API is already platform-generic; `Capacitor.isNativePlatform()` is already true on both platforms, so no iOS-specific branching exists in the UI code below. iOS stays CI-build-only (`.github/workflows/ios.yml`, unsigned, `xcodebuild -sdk iphonesimulator`), consistent with the rest of Goal 4's iOS work — there is no on-device iOS verification in this plan.
- No PRs, no pushes. All commits land on the local feature branch in the worktree; leave it for the user to merge/push.

```python
import pty, os, time, select, sys

master, slave = pty.openpty()
pid = os.fork()
if pid == 0:
    os.close(master)
    os.setsid()
    os.dup2(slave, 0)
    os.dup2(slave, 1)
    os.dup2(slave, 2)
    os.execvp("npx", ["npx", "cap", "migrate"])
else:
    os.close(slave)
    end = time.time() + 90
    while time.time() < end:
        r, _, _ = select.select([master], [], [], 1)
        if master in r:
            try:
                chunk = os.read(master, 4096)
            except OSError:
                break
            if not chunk:
                break
            sys.stdout.buffer.write(chunk)
            sys.stdout.flush()
            if b"Y/n" in chunk or b"?" in chunk:
                time.sleep(0.3)
                os.write(master, b"y\r")
    try:
        os.kill(pid, 9)
    except Exception:
        pass
```

- [ ] **Step 4: Implement `ScanButton` and `ScanResult` in `sources.jsx`**

Replace `dashboard/src/sources.jsx` in full:

```jsx
import { useState } from 'preact/hooks'
import { Capacitor } from '@capacitor/core'
import { mDNS } from '@devioarts/capacitor-mdns'
import { sources, sourceState, addSource, removeSource, normalizeBase } from './sources.js'

const MDNS_NAME_PREFIX = 'rtl433-'

export function SourcesView() {
  return (
    <>
      <ul id="source-list">
        {sources.value.map(base => (
          <li key={base}>
            <span class="dot" data-state={sourceState.value.get(base) || 'connecting'} />
            <span class="url">{base}</span>
            <button class="rm" title={`Remove ${base}`} onClick={() => removeSource(base)}>✕</button>
          </li>
        ))}
      </ul>
      <ScanButton />
      <SourceForm />
    </>
  )
}

function ScanButton() {
  if (!Capacitor.isNativePlatform()) return null
  const [state, setState] = useState({ status: 'idle', found: [] })

  async function scan() {
    setState({ status: 'scanning', found: [] })
    const result = await mDNS.discover({ type: '_http._tcp.', timeout: 4000 })
    const found = (result.services || []).filter(s => s.name && s.name.startsWith(MDNS_NAME_PREFIX))
    setState({ status: 'done', found })
  }

  return (
    <div id="mdns-scan">
      <button type="button" onClick={scan} disabled={state.status === 'scanning'}>
        {state.status === 'scanning' ? 'Scanning…' : 'Scan for receivers'}
      </button>
      {state.status === 'done' && state.found.length === 0 && (
        <p class="hint">No receivers found.</p>
      )}
      {state.status === 'done' && state.found.length > 0 && (
        <ul id="mdns-results">
          {state.found.map(svc => <ScanResult key={svc.name} svc={svc} />)}
        </ul>
      )}
    </div>
  )
}

function candidateBase(svc) {
  const host = (svc.hosts || [])[0]
  if (!host) return null
  const hostPart = host.includes(':') ? `[${host}]` : host
  return normalizeBase(`http://${hostPart}:${svc.port}`)
}

function ScanResult({ svc }) {
  const base = candidateBase(svc)
  const already = base && sources.value.indexOf(base) >= 0
  return (
    <li>
      <span class="url">{svc.name}{base ? ` — ${base}` : ' (no address)'}</span>
      <button type="button" disabled={!base || already} onClick={() => base && addSource(base)}>
        {already ? 'Added' : 'Add'}
      </button>
    </li>
  )
}

function SourceForm() {
  let input
  return (
    <form id="source-form" onSubmit={(ev) => {
      ev.preventDefault()
      if (!addSource(input.value)) {
        input.setAttribute('aria-invalid', 'true')
        return
      }
      input.removeAttribute('aria-invalid')
      input.value = ''
    }}>
      <input
        id="source-url"
        type="url"
        placeholder="http://bridge.local:8080"
        aria-label="Source base URL"
        ref={(el) => { input = el }}
        onInput={() => input.removeAttribute('aria-invalid')}
      />
      <button id="source-add" type="submit">Add</button>
    </form>
  )
}
```

`candidateBase()` reuses `normalizeBase()` (already handles the default-port-80 collapse via `URL.origin`, plus validates the constructed URL), rather than re-implementing that logic. The `host.includes(':')` check brackets IPv6 literals (`fe80::1` → `[fe80::1]:PORT`) — the spec's snippet didn't handle this, but the plugin's docs list IPv6 as a possible resolved host, so an unbracketed literal would build an invalid URL.
